# Python-internship-Elevate-Labs
 Command-Line Calculator (Python)

 Overview
This project contains **two versions** of a Python-based **Command-Line Calculator**.  
Both perform basic arithmetic operations such as **Addition**, **Subtraction**, **Multiplication**, and **Division** — directly from the terminal.

 Version 1: Simple Calculator
 File:
`Simple_Calculator.py`

 Description:
A basic **command-line calculator** that takes user input for operation choice and numbers.  
It supports looping until the user decides to exit.

 Features:
- Uses functions for each arithmetic operation.
- Continuously runs until “Exit” is chosen.
- Handles division by zero with an error message.


Version 2: Fancy CLI Calculator (with Color)
File:
Fancy_Calculator.py

 Description:
An upgraded, colorful version of the calculator that uses the colorama library to display attractive text colors in the terminal.

 Requirements:
Install Colorama before running:  pip install colorama

 Features:
Adds color and formatting for a better CLI experience.
Displays menu options in cyan, yellow, and magenta.
Keeps running in a loop until “Exit” is selected.
